**Fresh-eyes re-QA'd the 4 `pending-second-qa` apps** (Kestra, code-server, Ollama, Dockge)

figure. **Kestra failed**: its Postgres/MySQL either-or dependency was modeled as two
`required:false` entries (deliberately, to avoid Defect Class #11's required+optional trap)
— but that meant `noExternalServices()` treated it as dependency-free, falsely listing it on
the "no external database" collection page, whose own headline claims "no separate database
or cache container." Kestra's official reference `docker-compose.yml` wires up Postgres by
default with no db-free standalone mode, making the page's claim false for Kestra specifically.

paperless-ngx's valkey/redis modeling), MySQL stays `required:false` as the documented
alternative. Also fixed the root template gap flagged back in LEARNINGS #65: `build.mjs` never
rendered a dep's `note` field, so the OR-relationship a harvester writes into JSON never
reached the page — now every dep note renders as prose under "External services," benefiting
any future multi-backend entry. All 4 promoted to live (36 live total). 57/57 green.
